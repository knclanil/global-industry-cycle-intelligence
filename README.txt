Readable Knowledge Graph update (Global / USA / India)

1. Open GitHub Desktop and select global-industry-cycle-intelligence.
2. Repository > Show in Explorer (or Finder).
3. Copy regional_rotation_graph.py from this ZIP into your repository's
   TOP LEVEL folder (next to app.py). Replace the existing file.
4. In GitHub Desktop: Commit to main > Push origin.
5. Once Streamlit redeploys, open Knowledge Graphs.

Three display options:
- Overview (fits screen): all 4 rotations, all available sector/factor
  signals, and company counts at right. Designed to be readable on one page.
- Focus on a sector / factor: all rotations and indices, with every
  individual company for your selected index.
- All individual companies: full graph including every company and link.
  Large graphs are necessarily tall; company names appear on hover when dense.

No data or cache builder changes. Use existing edge snapshots generated by
Refresh Knowledge Graphs GitHub Action. This only changes the presentation.
