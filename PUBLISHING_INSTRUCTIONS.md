# Publishing the updated Wiki

This ZIP contains Markdown files, **not** a GitHub Wiki publication. Review the updated pages, especially `HOLDINGS_LEADERSHIP_WIKI.md`, `KNOWLEDGE_GRAPH_WIKI.md`, and `WIKI_HOME.md`.

To publish to the repository GitHub Wiki, clone the repository's separate `.wiki.git` repository (GitHub Wiki must be enabled and initialized), copy/rename pages to Wiki page names such as `Home.md`, `Holdings-Leadership.md`, and `Knowledge-Graph.md`, update links to those page names, then commit and push. Alternatively, add the Markdown files to your main repository and link them from its README. A main-repository commit **does not automatically update** the GitHub Wiki.

The existing `WIKI.md` and topic pages are preserved as supplied. Their older formulas may be outdated; prioritize the new current-methodology page and audit legacy references before public publication.
