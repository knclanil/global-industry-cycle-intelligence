This directory is populated by `scripts/refresh_india_financials.py`.
It intentionally contains NO invented/sample financial data.

* companies/ — individually keyed financial statement/quote snapshots
* company_financial_summary.csv — a financial row per company with cached data
* index_financial_summary.csv — descriptive medians over unique index/factor constituents
* refresh_status.csv — last provider errors and successes
* build_summary.json — coverage counts and refresh timestamps

See INDIA_FINANCIAL_ANALYSIS_GUIDE.md for provider data rights, provenance and deployment.
