USA Knowledge Graph Company Memberships — Precomputed Fundamental Rank Integration

WHAT THIS UPDATE DOES
- USA only: adds Final Rank, Total Rank, and Rank Status after Ticker in
  "All verified company memberships · table filters".
- Sorts companies by Final Rank, then name; missing/unranked companies last.
- Provides optional read-only details showing ROE, Current Ratio, Operating
  Margin, Net Margin, EPS Growth, individual ranks, Market Cap and its tie rank.
- Uses existing data/usa_research/fundamental_rankings.csv produced by the USA
  financial pipeline. Does not recalculate financial ranks using only selected companies.
- Does not change the knowledge graph, its filters, display limits, or other regions.
- Does not drop a company if ranks/financials are missing. Does not invent values.

INSTALL
1. Extract ZIP. Copy usa_graph_membership_ranks.py, scripts/ and INSTALL_WINDOWS.bat
   into the matching locations of your local repository.
2. Double-click INSTALL_WINDOWS.bat in the repository root.
3. Confirm SUCCESS; regional_rotation_graph.py will be updated with an
   idempotent, anchored edit. Existing file is backed up locally with suffix
   .py.pre_usa_rank_backup. Do not commit this backup.
4. In GitHub Desktop, commit the changed regional_rotation_graph.py and new
   usa_graph_membership_ranks.py, then Push origin.
5. Confirm that data/usa_research/fundamental_rankings.csv already exists in
   GitHub (generated by your completed USA financial ranking workflow).

The table's primary Final Rank comes from the entire USA universe. If a company
has no five-metric rank or is excluded as a financial institution, its rank
remains empty and it sorts after valid ranked companies.

The CSV currently uses ticker identity. Tickers with more than one matching
ranking row are treated as ambiguous and intentionally not joined. No website
scraping or live SEC calls run when viewing the graph.
