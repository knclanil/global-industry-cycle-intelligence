# India Sector/Factor Holdings + Company Financial Analysis

## What was added

This release preserves **Company Financial Research (US)**, **Company Financial KPIs (US)**, **India Sector & Factor Holdings**, and the pre-existing 31-index historical change tracking. It adds two independent pages, **India Company Financial KPIs** and **India Sector & Factor Financials**. **No rankings or leadership scores** are generated.

### Data origin (do not interchange)

| Data | Authoritative input used in this application | Scope and caveat |
|---|---|---|
| Index membership, company symbols, ISIN, industry | The **31 user-provided NSE Indices constituent CSVs** | Index constituents, not fund holdings weights. Nifty 50/100/200/500 are nested parent universes, not separate cap classes. |
| Index additions/removals and ticker changes | Successive stored, validated NSE snapshots | First snapshot is a baseline; a change is detected only after a later changed snapshot. Download timestamp is **not** NSE effective/rebalance date. |
| Income / balance sheet / cash flow | **Optional Yahoo Finance via `yfinance`**, `.NS` ticker, collected in GitHub Actions | May be unavailable/stale. Publisher may use standalone or consolidated figures; **consolidation scope is not asserted without verification**. Quarterly rows are Yahoo's reported quarters, not calculated by subtracting annual/YTD figures. |
| Quote / current market capitalization | Optional Yahoo quote snapshot | As-of UTC is **retrieval time**, not exchange tick timestamp. Quote currency must equal statement currency before generating cross-source valuation ratios. |
| Consolidated Indian financial reporting | [Screener.in](https://www.screener.in/company/RELIANCE/consolidated/) **external research link per ticker** | Links are provided, **no automated download, mirroring, or redistribution of Screener data** is performed. Direct import requires separate permission/licence and an adapter, not included. |

**Important data rights:** yfinance's own documentation says its Yahoo Finance access is for **personal use**. Yahoo content and Screener.in content can have restrictions on automated collection and republication. If you plan to display financial snapshots on a **public Streamlit website or publish them in a public GitHub repository**, ensure you have appropriate data rights first, or replace the Yahoo collector with a licensed, redistribution-permitted financials feed. These provider methods are implementation options, **not a representation that public redistribution is authorized**. Read the sources' current terms.

### Deployment

1. Deploy the **contents** of `nightly_build/` to the GitHub repository **root**. Do not delete the existing `data/india_holdings/` tree; it holds your 31 verified source snapshots and history.
2. Verify `requirements.txt` includes `yfinance`, pandas, Plotly and Streamlit.
3. First run **Actions → India NSE Constituents Refresh**. The `data/india_holdings/build_summary.json` file should show `loaded_indices` greater than zero. Your previous result of **31 indices, 328 unique securities and 975 index memberships** was provided in conversation; **these actual NSE records were not included in this ZIP**.
4. If you have rights to retrieve and display Yahoo-derived data in your target deployment, run **Actions → India Company Financials Refresh → Run workflow**. Default run attempts **the full eligible NSE universe** (`limit=0`), and the workflow's optional `symbols` input supports e.g. `RELIANCE,TCS,INFY` for targeted collection.
5. The workflow saves `data/india_financials/companies/<hashed-company-key>.json`, a company KPI summary CSV, a source-index/factor-family financial summary CSV, and detailed status/coverage files. It commits the results. Verify these outputs and your usage rights before enabling collection into any public repository.
6. Restart Streamlit. Under the existing navigation, open **Global Intelligence → India Company Financial KPIs** and **Factor Analysis → India Sector & Factor Financials**.

**No SEC_USER_AGENT key is needed for the India financial pages.** They do not make SEC requests. The original USA SEC-driven pages remain unchanged.

### Local commands

```bash
# Collect a specific Indian company first (requires existing NSE companies.csv)
python scripts/refresh_india_financials.py --symbols RELIANCE --limit 1

# Gradually process the universe; successful snapshots are not refetched for 14 days
python scripts/refresh_india_financials.py --limit 0

# Recompute the summary CSVs from existing snapshots without any Yahoo calls
python scripts/refresh_india_financials.py --rebuild-only

# If a specific cached source row needs replacing; use with restraint
python scripts/refresh_india_financials.py --symbols RELIANCE --force --limit 1
```

### What is shown

**India Company Financial KPIs** offers a searchable company picker tied to the verified NSE directory, with Overview, Growth & Margins, Balance Sheet, Cash Flow, Asset & Intrinsic Value, Annual/Quarterly Trends, source financial statements, and official-source/independent-research links. The user can drill down from India holdings to the company KPI page. Financial figures default to **INR crore** for INR statements and preserve each quote's own currency.

**India Sector & Factor Financials** shows each source index's unique membership count, annual financial coverage, and **unweighted constituent medians** for revenue growth, margins, ROE, valuation, etc. It includes separate **Factor Family** summaries where a company appearing in three Value subindices is counted once, constituent KPI drilldowns, and the sector × factor heatmap. It is **not an index return**, index-weighted financial metric or leadership score. No top-10 weights are invented.

### Asset/intrinsic value mathematics and data limitations

* Book value/share = **common equity / common shares**. The statement-period share count is preferred; if the quote share count is used instead, the interface flags the date mismatch.
* Tangible book/share is shown only when both goodwill and intangible assets are reported.
* Graham Number = `sqrt(22.5 × positive annual diluted EPS × positive book value/share)`. Missing or nonpositive inputs => N/A. It is a classical *screen* rather than fair value.
* NCAV/share = `(current assets − total liabilities − preferred claims)/common shares`. If preferred claims aren't known, this metric remains N/A.
* Liquidation model is a **hypothetical scenario**, and by default N/A when preferred claims are unknown; an explicit **user assumption** can set them to zero. This is not a market sale price or recovery guarantee.
* Simple five-year FCF-proxy DCF = projected company FCF discounted to a present per-share figure. It is explicitly **not a verified FCFE or enterprise DCF** and is disabled for missing/nonpositive cash flow or invalid terminal/discount inputs.
* Quarter-level EPS is never used to compute annual P/E or Graham Number, and quarterly FCF is never annualized to compute FCF yield without a valid trailing twelve months calculation. When missing, the KPI remains N/A.
* Bank and insurer metrics require separate sector-specific analysis; generic ratios should not be mistaken for a health grade.
* Source periods and quote retrieval UTC are always shown. Ratios with currency-mismatched sources are suppressed.

### Troubleshooting

* **0 companies** on India holdings: check `data/india_holdings/build_summary.json` and confirm that **NSE indices refresh committed `companies.csv` and `constituents.csv`** to the same branch Streamlit deploys.
* **0 companies with financials:** run the dedicated **India Company Financials Refresh** workflow; NSE data collection alone doesn't fetch balance sheets.
* **Yahoo 429 / missing statements:** inspect `data/india_financials/refresh_status.csv`. Previous valid cached snapshots are preserved. There is no CAPTCHA, proxy or access-control bypass; pause or use an appropriately licensed data provider if restricted.
* **Data missing for a symbol:** check that the `.NS` quote matches the NSE ISIN. Do not substitute arbitrary `.BO` or another company ticker without explicit verification.
* **Financial values differ from Screener consolidated:** Yahoo may use a different consolidation basis, reporting period, metric definition, or data revision. Use the external Screener link for cross-checks; don't automatically blend inconsistent statements.
* **Pages slow:** all financial calculation happens in background; Streamlit only loads precomputed summaries and one selected company JSON. If your app is slow, inspect overall hosting resources and non-India pages separately.

### Verification

Unit tests use **synthetic fixtures only**. Their test numbers are not production financial facts. The code was verified for compilation and tested locally with mocked Yahoo financial statements. No live Yahoo/NSE call or deployed Streamlit screenshot was run in the package-building environment.


## Live direct ticker research (MGL example)

The **India Company Financial KPIs** page now includes a **Direct NSE ticker** mode (e.g. `MGL` or `MGL.NS`). Click **Fetch live Yahoo financials** to request annual and quarterly statements on demand; the page remains fast on ordinary reruns and falls back to the last saved statement when Yahoo rejects the request. NSE constituent membership is never invented for ad-hoc tickers. The GitHub financial refresh action accepts `limit=0` for the entire eligible NSE universe, and optional `symbols=MGL` for one ticker even if it is not in the index snapshot. For details see `INDIA_LIVE_FINANCIALS_SETUP.md`.
